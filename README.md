**FEATURES**

- Change songs using the arrow keys.
- Import playlists directly from the Music app (macOS only).
- Import songs directly from your music folder (Windows).
- Built-in equalizer with several presets.
- Support for multiple languages.
- Customize the visualizer bar styles.
-Play and Pause using space bar
-Edit Song names and Song List from the app

-What's New?
